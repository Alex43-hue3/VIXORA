NETVISION 1.1 V8

Mejoras principales:
- Mando remoto con navegación contextual por Inicio, TV, Películas, Series y reproducción.
- Navegación vertical real dentro de las cuadrículas de películas/series.
- TV en vivo abre la lista de canales al entrar desde el mando.
- Eliminado el buscador y la lista de TVs guardadas del mando.
- Se elimina el bucle de MutationObserver que podía saturar la conexión y provocar pausas del mando.
- Un solo foco remoto visible a la vez.
- Ajustes, Mi lista y Perfil se excluyen entre sí para evitar modales apilados.
- Pantalla completa y Activar reproducción accesibles desde el mando.
- Volumen +, volumen -, silencio, anterior/siguiente y reproducción/pausa.
- La activación de reproducción muestra un aviso en la TV si el navegador bloquea autoplay.

La comunicación TV/teléfono utiliza PeerJS.
